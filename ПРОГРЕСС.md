## Ключевые решения

1. Расписание хранится **по конкретным датам**, каждую неделю новое
2. Все старые недели сохраняются в БД (можно искать пропущенные пары)
3. Перевод студентов между группами — через `student_group_history`
4. Преподаватели — только справочник, не обязательно пользователи
5. Связь `users.teacher_id` (nullable) — опционально
6. Старые группы пользователь переименует сам, алиасы помогут
7. `init_db()` синхронизирован с миграциями v3–v6 (идемпотентно)
8. Права проверяются либо через `@permission_required`, либо через
   `_user_owns_journal` для журналов
9. Все секреты — в `.env`, не в коде и не в git
10. Интервалы пар хранятся в `Config.TIME_INTERVALS_BY_DAY` (по дням недели),
    а не захардкожены в шаблоне
11. Форматирование времени, цвета оценок и посещений — через хелперы
    в `context_processor` (`format_time`, `grade_color`, `attendance_color`)
